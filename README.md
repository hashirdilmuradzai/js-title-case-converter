# JavaScript Title Case Converter

A beginner JavaScript project that converts a string into **Title Case**, where the first letter of each word is capitalized and the remaining letters are converted to lowercase.

## Example

```text
Input:
mY NaMe IS haShIR

Output:
My Name Is Hashir
```

## Features

- Convert each word into Title Case
- Capitalize the first letter of every word
- Convert remaining letters to lowercase
- Handle multiple words in a string

## Technologies Used

- JavaScript

## JavaScript Concepts Used

- Strings
- `split()`
- `for` loop
- `toUpperCase()`
- `toLowerCase()`
- `slice()`
- String concatenation
- Arrays

## Purpose

This project was created to practice JavaScript string manipulation, arrays, loops, and built-in string methods.
